# Infinity Code Nexus — Power BI Masterclass Batch 01

## Practical Learning • Hands-on Projects • Real Student Outcomes

**Infinity Code Nexus (ICN)**

Power BI Masterclass — Batch 01 was a practical, project-based learning program designed to help participants build foundational and applied skills in **Microsoft Power BI and Data Analytics**.

This repository serves as the public portfolio and proof-of-work collection for Batch 01, bringing together participant projects, dashboards, documentation, datasets, student feedback, and selected video testimonials.

---

# About the Masterclass

The Power BI Masterclass focused on learning through practical implementation.

Participants progressed from Power BI fundamentals to data preparation, modeling, DAX, visualization, dashboard development, and complete project-based solutions.

The program emphasized:

- Concept understanding
- Live demonstrations
- Hands-on practice
- Dataset-based learning
- Dashboard development
- Business-oriented analysis
- Project documentation
- Portfolio development

# What Participants Worked On
